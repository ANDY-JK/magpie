## 本轮已补的行为

- 添加供应商：改为现行版的“列表下方 sheet”，不再是居中弹窗；Esc、取消、× 都能关。
- 供应商·删除 → 确认 modal；供应商行右键 → 排序/编辑/删除菜单。
- 会话·重命名/移动 → 表单 modal。
- 设置·语言 → 选择 modal；设置·快捷键 → 录制 modal。
- 智能体·＋添加 → 添加 modal。
- 用量·请求·详情 → 请求 modal。
- 顶栏·更新、底栏·退出 → 提示 / 确认 modal。
- 插件开关 → 点击即切换，详情面板状态同步。
- 顶部「状态」→ 正常 / 空 / 加载；空状态与骨架屏可在列表页验证。
- 所有已接的 modal/sheet/menu 都支持 Esc、点背景、× 关闭。
- 网关·密钥列表 → 编辑/删除；编辑打开 modal，删除打开确认。
- 设置·模型 → 模型选择 modal；设置·界面字体 → 两列字体 modal。
- 添加 sheet·导入 → 导入配置 modal。
- 状态增加「错误」：读取失败条 + 重试。
- 焦点环已加。
