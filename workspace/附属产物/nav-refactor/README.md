# magpie 界面原型 · 说明台账（非入口）

> 入口是 `index.html`。本文件只做文字台账，不并列为“当前页面”。

主文件：`skeleton-components.html`。纯静态，打开即可。顶部可切骨架宽/窄、明/暗。

## 外壳已定，不再重画

窗口骨架之前已经定稿，这一页不重新设计，只把外壳里的模块抽出来：

- 一级：5 个分区（对话 / 模型 / 分析 / 隐私 / 扩展）
- 二级：分区里的页面（2–3 个）
- 三级：页面自己的标签（用量 5、资源库 6、插件 3、设置 9）
- 四级：顶部工具栏（每页一个）
- 设置不在分区里，走侧栏脚 / 顶栏齿轮

宽窗 / 窄窗只换二级导航的位置，层级和模块都不变。

## 通用组件

### 导航（4 个）
一级分区行、二级页面行、三级标签条、顶部工具栏。

### 内容（11 个）
列表行、统计块、图表、卡片、开关、分段控件、搜索框、按钮（普通/主）、状态点（3 种）、空状态、骨架屏。

每个组件只有一种写法、一套样式，多页共用；页面不自己另画行或卡片。

## 页面怎么拼

页面 = 窗口骨架 + 二级页面 + 三级标签 + 顶部工具栏 + 内容组件。
示例页（供应商、用量）用的是同一批积木。

## 复用规则

- 一个模块只有一种写法、一套样式
- 层级固定：分区 → 页面 → 标签 → 工具栏
- 宽窗 / 窄窗只换位置，不换模块
- 新页面先找现成模块；找不到再加

## 标注层：每页可定位、可描述

`all-pages.html` 顶部有「标注」开关。打开后每页的每个区域都有编号和名字；点编号会选中该区域（变绿），下方表格同步高亮。

- **本页元素表**：编号 · 区域 · 由哪些组件组成 · 改动位置
- **组件索引**：C01–C16，组件 · 样式类 · 用在哪 · 改这里
- **描述方式**：页面 · 区域号 · 区域名，例如「供应商 · 2 · 列表 的行距改小」→ 改 C01 列表行（`.item`）的 padding
- 外壳（标题栏 / 一级分区 / 二级页面 / 底栏）见 `skeleton-components.html`，不重复列

截图：`spec-providers-narrow.png`、`spec-usage-narrow.png`、`spec-settings-wide.png`、`spec-plugins-narrow.png`、`spec-routing-narrow.png`、`no-spec-providers-narrow.png`。

## 全部页面 + 页内视图（都统一组件）

`all-pages.html` 现在有 **11 个页面，展开为 32 个视图**（8 个单页 + 24 个页内视图）。点页内标签会真正换内容，不是只换高亮：

- 用量 5：概览 / 请求 / 会话 / 上下文 / 榜单
- 资源库 6：指令 / MCP / 技能 / 钩子 / 子代理 / RTK
- 插件 3：内置 / 发现 / 已安装
- 设置 9：通用 / 额度 / 网络与共享 / 模型 / 隐私 / 可观测 / 同步与备份 / 插件 / 关于

每个视图都只用同一套组件；窗口下方的“本页元素”表会跟着当前标签变。24 个页内视图已逐个核对：区域名与表格行全部一致。

截图：`page-*.png`（11 个页面）、`tab-<页面>-<序号>.png`（24 个视图）。

列表型：智能体、会话、供应商、诊断、掩码、资源库
卡片型：路由、网关
数据型：用量、指标
开关型：插件、设置

没有页面私自造新组件。

## 弹窗与浮层（30 个）

`overlays.html` 把窗口之外的界面补齐了。特别说明：**点供应商行是原地展开编辑器，不是 modal**；添加供应商才是底部 sheet。

- 供应商：行展开、添加 sheet、右键菜单、导入配置、添加账号/登录
- 通用：密钥编辑、确认删除、模型选择器、更新提示
- 其它：会话详情、资源详情、智能体行展开、网关调用详情
- 特殊形态：托盘面板、托盘右键菜单、手机窄屏

页面底部有一张逐项清单（33 行），每项标了“已画 / 外部 / 组件覆盖”；OAuth 登录页、系统文件选择、浏览器授权属于系统/外部页面，不画。

截图：`overlays-light.png`、`overlays-dark.png`。
